# Student Academic Performance Calculator

## 📌 About the Project
A beginner-friendly Python program that calculates a student's academic performance based on marks obtained in multiple subjects.

## ✨ Features
- Accepts the student's name.
- Takes the number of subjects as input.
- Accepts marks for each subject.
- Calculates total marks and average percentage.
- Assigns a grade based on the percentage.
- Displays a performance description.

## 🛠️ Technologies Used
- Python 3
- Variables and Data Types
- `input()` and Type Conversion
- `for` Loop
- Conditional Statements (`if`, `elif`, `else`)
- Arithmetic Operations

## 📊 Grading System

| Percentage | Grade | Performance |
|---|---|---|
| 90–100% | A+ | Outstanding |
| 80–89.99% | A | Excellent |
| 70–79.99% | B | Very Good |
| 60–69.99% | C | Good |
| 50–59.99% | D | Average |
| Below 50% | F | Needs Improvement |

## 🚀 How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   ```bash
   python academic_performance.py
   ```
